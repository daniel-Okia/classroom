# Licensing checklist (before any public release)

| Item | Status | Action |
|---|---|---|
| NCDC syllabi/guidelines (downloaded for local testing) | Test-only. © NCDC, all rights reserved | Written permission from NCDC, or remove. Only topic names are used in `taxonomy.json` |
| UNEB past papers and marking guides | Not ingested | Request permission; until then link out only |
| Exinet, Exotic Notes, Yaaka | Link-only / excluded | Do not copy. Terms forbid it |
| Original lessons (4 seeds) | AI-drafted, unreviewed | Teacher review; owner chooses a licence (e.g. CC BY-SA) |
| Bible text | KJV references only; no verse text stored yet beyond short reflections | When embedding text use KJV/WEB (public domain). Do NOT embed NIV, ESV, Luganda Bible without written permission |
| Fonts | Nunito (SIL OFL) planned, self-hosted | Add font files and licence |
| Icons | Generated placeholder | Replace with a real logo |
| Dependencies | MIT/Apache/ISC mostly; run `pnpm licenses list` before release | Review copyleft |
| Africa's Talking / payment providers | Not integrated | Terms review before Phase 2 |
